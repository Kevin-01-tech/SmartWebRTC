# SMART WebRTC

SMART WebRTC is a browser-based real-time communication platform built with React, Node.js, Socket.IO, and WebRTC.

## Live Demo

- **Frontend:** https://smart-web-rtc-rwfe.vercel.app
- **Backend:** https://smart-webrtc-server.onrender.com

Open the frontend link to use the project.

## Features

- Join meetings using a name and room ID
- Real-time audio and video communication
- Text chat
- Microphone and camera controls
- Screen sharing
- Network-status monitoring
- AI-based network-quality prediction
- Adaptive quality recommendations
- AI meeting summary

## Technologies

- React.js and Vite
- Node.js and Express.js
- Socket.IO
- WebRTC
- JavaScript, HTML, and CSS
- Vercel and Render

## Run Locally

### Backend

```bash
cd server
npm install
node server.js
```

### Frontend

```bash
cd client
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```
